# v0.7.1 计划：Better Skill 入口迁到「设置 → 插件」页 Tab

## 目标

把当前挂在设置侧栏的独立入口「Better Skill」整体迁到 **设置 → 插件** 页的 Tab 行（位于「已安装」与「发现」之后）；设置侧栏不再出现独立条目。页面内容保持 v0.7.0 的三块功能：描述汉化 / 插件管理 / 技能管理。

## 已核实契约（DSH 0.2.2-rc.1）

- `plugins.tab`：client slot，`kind: "list"`、`scope: "root"`，由插件页插件（main 中的 entry，registrant `tk`）声明；当前 occupant 仅 `discover`（order 0）。
- 注册参数：`{ name:'plugins.tab', id: <必填>, order?: number, label?: string | (() => string) }`；label thunk 每次投影重读。
- ownerProps：`{ install(target), openPackage(packageName) }`；标准 props 不含 `t`，文案用 `ctx.locale.bind(NS)`。
- `ctx.slots.inject(key, cb)`：已声明则同步执行，未声明则在声明提交后执行；折叠时 dispose；插件卸载取消等待（安全，不会卡 entry 在 loading）。
- 现有 client.js：`inject: ['slots','locale']`；`apply()` 内注册 `settings.section`（:3361 附近）；`BetterSkillPage`（:3262）无页头，直接渲染三 Tab；`PAGE_ORDER`/`BetterSkillIcon` 已无实际注册。

## 实现

### A. client.js

1. 删除 `settings.section` 注册块，替换为：

```js
ctx.slots.inject('plugins.tab', function () {
  return ctx.slots.register({
    name: 'plugins.tab',
    id: 'skill-desc-zh',
    order: 20,
    label: function () { return t('nav'); }
  }, function BetterSkillPanel(props) {
    return h(BetterSkillPage, Object.assign({}, props, { t: props.t || t, ctx: ctx }));
  });
});
```

2. 保留 `apply()` 外层 try/catch（console.error + `window.__SDZH_CLIENT_ERROR__`）。
3. 删除无用的 `PAGE_ORDER` 常量与 `BetterSkillIcon` 组件（含 `__test__` 导出）。
4. `inject` 保持 `['slots','locale']`；不新增服务依赖；`installPluginMarketBridge` 降级逻辑不动。
5. ownerProps 原样透传。

## 边界与失败模式

- 插件页不可用（旧宿主/插件页被禁用）：`plugins.tab` 未声明，inject 保持等待，不注册、不抛错，仅 console.info。
- 重复 id：使用独占 `skill-desc-zh`。
- locale 切换：label thunk 自动跟随。
- 启动失败保护：去 immediately + try/catch；若仍失败 DSH 自动回滚 bundle 并写 `crash-*-web-boot.log`。
- 回滚：`git checkout 4e332de -- .`（v0.6.0）或 revert 本次提交；profile 可 `set_bundle enabled=false`。
