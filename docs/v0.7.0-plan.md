## 二、插件索引数据源（客户端 Remote）

`ctx.remote.pluginMarket`（`@deepseek-ai/dsh-plugin-market`，profile 已启用，`profiles/desktop/cordis.patch.yml:68`）：

- `listIndexes()` → `{url, title?, description?, error?}[]`（不发起网络请求）。
- `search(url, query)` → `{url, title, description?, metadata{categories,labels,sortKeys}, fetchedAt, entries, total, nextOffset}`。
  - `query = {text?, category?, labels?, sort:{kind:'index'|'relevance'|'published'|'key',...}, offset, limit(1-100), refresh?, fetchedAt?}`。
- entry：`{name, title?, description?, icon?, author?, homepage?, repository?, metadata, versions, defaultVersion?, installation{status,installedVersion?}}`。
- version：`{version, publishTimestamp, source, engines, install{spec,registry?}, compatibility}`；compatibility 为 `{compatible:true}` 或 `{compatible:false, runtimeVersion, requirements, exempted}`。
- 安装状态：`not-installed | installed | update-available | different-version | provided`。
- 客户端用法（与原生发现页一致）：
  - `const remote = ctx.remote; await remote.pluginMarket.listIndexes()`；
  - 事件：`remote.$on('plugin-market/changed', cb)`、`remote.$on('plugin-manager/changed', cb)`、`ctx.on('connection/reset', cb)`（均返回 disposer，必须在 `ctx.effect` 里统一释放）。
  - 本地化文本：`ctx.locale.resolveText(text)`（`LocalizedText = string | {en, ...}`）。
- profile 当前已配置索引源：`https://cdn.dsh.so/market/index.json`、`https://cdn.dsh.so/market/top-rank.json`。

### C. 插件索引子页（automation-engineer，依赖 A+B 完成）

`插件管理` Tab 顶部新增二级切换「已安装 | 插件索引」（`role="group"` + 两个 `aria-pressed` 按钮，非嵌套 tablist）。

- 数据全部走 `ctx.remote.pluginMarket`（不新增 host HTTP 路由）。
- 自动同步：进入页/切回子页、`plugin-market/changed`、`connection/reset` → 重读 `listIndexes()`；`plugin-manager/changed` → 重跑当前 `search` 刷新安装状态。
- 索引源：下拉选择（`resolveText(title)`，缺失显示 URL 主机名；有 `error` 的源标不可用及原因）；无源空态引导去 设置→插件→发现 添加。
- 搜索：250ms 防抖；默认 `sort={kind:'index'}`、`limit:50`；「加载更多」用同一 `fetchedAt` 追加去重。
- 行：图标（`<img referrerpolicy="no-referrer" loading="lazy">`，失败回退首字母方块）+ 标题/包名 + 一行描述 + 作者 + `defaultVersion` + 安装状态徽章 + 兼容性提示（`compatible:false` 显示「不兼容（宿主 X）」；`exempted` 标「已豁免」）。
- 展开详情：作者/主页/仓库外链（`rel="noreferrer"`）、分类/标签、全部版本（SemVer 降序，标推荐/预发布/已安装/不兼容/豁免）、安装目标 `spec`/`registry`、「在插件页安装」提示。
- 错误/加载：sources 失败 → 整块错误+重试；search 失败 → 保留旧列表+错误条+重试（可 `refresh:true`）；骨架行、空结果态。
- 降级：`ctx.remote.pluginMarket` 不存在 → 「当前宿主未提供插件索引服务（需要启用 DSH 插件发现）」，其他功能不受影响。
- locale：zh/en 各新增约 30 个 `index.*` 键；`scripts/check-client.mjs` 的 key 计数与 required keys 同步。
- 明确非目标：不实现索引源增删/排序管理；不实现条目安装；不实现完整 Markdown 详细介绍（`readEntryDetail`）。索引文本是第三方数据，仅展示、不执行。
